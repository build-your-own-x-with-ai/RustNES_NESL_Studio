# Contract: 音乐与自定义音效（v5 增量）

## 音乐
```nesl
music THEME = "T140 O4 L8 E G >C< G | A4 G4 R2";
music BASS  = ["O2 L4 C G C G", "A E F G"];     // 多个字符串依次连接
music HARM  = "O4 L4 G E F D";

play_music(THEME);               // 只有旋律
play_music(THEME, BASS);         // 旋律 + 低音
play_music(THEME, BASS, HARM);   // 旋律 + 低音 + 和声
stop_music();
```
三个声部：旋律 = 方波 1，低音 = 三角波，和声 = 方波 2（音效播放时暂时让出）。播完自动循环。

### MML
| 写法 | 含义 | 默认 |
|---|---|---|
| `C D E F G A B` | 音符，可跟 `+`/`#`（升）或 `-`（降），再跟长度和附点 `.` | |
| `R` | 休止 | |
| `4` `8` `16` … | 长度：4 = 四分音符，1-64 | `L4` |
| `L n` | 默认长度 | 4 |
| `O n` / `>` / `<` | 八度 0-7 / 升一个八度 / 降一个八度 | `O4` |
| `T n` | 速度（每分钟四分音符数，30-300） | `T120` |
| `V n` | 音量 0-15（方波声部） | `V12` |
| `@n` | 占空比 0-3（12.5% / 25% / 50% / 75%） | `@2` |
| `&` | 与下一个音符连奏（不加间隙） | |
| `\|`、空白 | 忽略（可用作小节线） | |

- 每个音符最后一帧自动静音，使相同音符连续时听得清；用 `&` 取消。
- 旋律与和声声部最低音为 A1，低音声部最低为 A0；最高 B7。

## 自定义音效
```nesl
sound LASER = (pulse, 0x30, 4, 10);          // (通道, 起始周期, 每帧周期变化, 帧数)
sound BOOM  = (noise, 12, 0, 30, 15);        // 可选第 5 项：最大音量（默认 12）
sound ZAP   = (pulse, 0x80, -6, 8, 10, 3);   // 可选第 6 项：占空比 0-3（默认 2）
sfx(LASER);
```
- 方波周期 8-2047（越大越低），噪声周期 0-15；变化量 -128..127；帧数 1-255。
- 与 `SFX_JUMP` 等内置音效共用引擎，合计最多 32 个。
- `stop_sound()` 停止全部声音（音乐、音效、`play_tone`）。

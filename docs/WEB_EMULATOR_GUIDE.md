### ⚠️ Mario 示例说明

**Mario 示例会显示黑屏和错误，这是正常的！**

**错误信息：**
```
没有找到调色板: 用 const PAL: [u8] = [...] 声明, 并调用 load_palette(PAL).
```

**原因：**

Mario 反编译代码只包含程序逻辑，不包含：
- ❌ 调色板定义
- ❌ 图形 tiles
- ❌ 关卡数据

这是反编译的正常限制（详见 `docs/WHY_BLACK_SCREEN.md`）

## 🎨 调色板和图形说明

### 为什么 Sprite 能运行而 Mario 不能？

**Sprite.nesl 包含：**
```nesl
// 调色板定义
const PAL: [u8] = [
    0x0F, 0x30, 0x10, 0x00,  // 4 个颜色
    // ... 更多颜色
];

// Tile 图形定义
tile 1 = [
    "..2222..",
    ".222222.",
    // ... 8x8 像素
];

fn main() {
    load_palette(PAL);  // ← 加载调色板
    // ...
}
```

**Mario 反编译代码缺少：**
- ❌ `const PAL: [u8] = [...]` - 调色板
- ❌ `tile X = [...]` - 图形定义
- ❌ 这些需要从原版 ROM 提取

# Implementation Plan: 音乐与自定义音效

**Branch**: `005-music` | **Date**: 2026-10-17 | **Spec**: [spec.md](./spec.md)

## Summary

新增独立模块 `mml.rs`：把 MML 文本编译成 2 字节事件流（纯函数，单元测试逐字节验证）。
运行时新增 NMI 驱动的三声部音乐引擎（每个声部展开生成一份代码，绝对地址，无需变址寄存器技巧），
音高通过编译进 ROM 的周期表查找（三角波查 `n+12`，因为同周期下三角波低一个八度）。
`sound` 声明扩展已有的音效表，表与表长改由代码生成在程序末尾输出。

| 原则 | 结论 |

## Design

### 事件格式（每个 2 字节）
| 首字节 | 第二字节 | 含义 |
|---|---|---|
| `0x00-0x5F` | 帧数 | 音符（n = 八度×12 + 半音，C4 = 48，A4 = 57），重新触发 |
| `0x80-0x8F` | 0 | 设置音量 |
| `0x90-0x93` | 0 | 设置占空比 |
| `0xFD` | 帧数 | 延续（长音拆分 / `&`），不重新触发 |
| `0xFE` | 帧数 | 休止 |
| `0xFF` | 0 | 结束，回到开头 |

时值：每个声部维护累计时间 `t`（帧，f64），事件帧数 = `round(t + d) − round(t)`。
断奏：没有 `&` 的音符 ≥ 2 帧时拆成 `[n, d−1] [0xFE, 1]`。

### 周期表
- `__per_lo/__per_hi`：108 项，`period(n) = round(1789773 / (16 · f(n))) − 1`，`f(n) = 440 · 2^((n−57)/12)`，钳制到 `[8, 0x7FF]`。
- 方波声部用 `n`（要求 n ≥ 21，即 A1）；三角波用 `n + 12`。

### 内存
| 地址 | 用途 |
|---|---|
| `$16-$17` | `NMI_PTR`：仅 NMI 使用的零页指针（用户零页变量起点改为 `$18`） |
| `$037E-$0393` | 3 个声部 × {ptr 2, start 2, timer, vol, duty} |
| `$0394` | `MU_ON` 位掩码 |
| `$0395` | `MU_NOTE` 临时 |

### 运行时
- `__music_tick`（NMI 末尾，渲染开关均执行）：每个声部 `timer−1`，到 0 时读取事件直到遇到带时长的事件；
  控制事件立即生效；`0xFF` 回到起点（编译期保证每首曲子至少有一个带时长的事件，避免死循环）。
- 方波：`$4000+b` = 占空比|`$30`|音量、`$4001+b` = `$08`、`$4002+b`/`$4003+b` = 周期；休止写音量 0。
  和声声部（方波 2）在 `SFX_TIMER ≠ 0` 时跳过所有寄存器写入。
- 三角波：音符 `APU_EN |= 4` → `$4015`、`$4008` = `$FF`、`$400A/$400B`；休止 `APU_EN &= ~4`。
- `play_music`：先清 `MU_ON`，设置各声部起点/计时器 1/默认音量与占空比，静音未用声部，最后写 `MU_ON`。

### 音效表
- `__sfx_table` 与 `__sfx_count` 由代码生成在数据区输出：5 个内置 + `sound` 声明（id = 5, 6, ...）。
- `__sfx`：`AND #$1F` / `CMP __sfx_count`。

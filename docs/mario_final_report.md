```nesl
if (!zero) {
    call_$90CC();
    t0 = 0xA5;
    // ...
}
}
```

### 问题和限制

#### 1. 函数调用语法 ⚠️

**当前：** `call_$90CC()`  
**问题：** NESL 不支持 `$` 在标识符中  
**解决方案：** 改为 `call_90CC()` 或 `sub_90CC()`

#### 2. 临时变量未声明 ⚠️

**当前：** `t0 = 0xA5;`  
**问题：** `t0` 未在变量部分声明  
**解决方案：** 在变量部分添加所有临时变量

#### 3. 条件表达式 ⚠️

**当前：** `if (!zero)`  
**问题：** `zero` 是 CPU 标志位，不是 NESL 变量  
**解决方案：** 转换为实际的条件表达式，如 `if (x == 0)`

#### 4. 不完整的函数体 ⚠️

某些复杂函数只生成了部分代码。

## 使用指南

### 三种反编译器

```bash
# 1. 基础反编译器（学习用）
nesc pseudocode mario.nes -o mario_basic.c
# 输出：基础的 C-like 伪代码

# 2. 增强反编译器（更好）
nesc enhanced-pseudocode mario.nes -o mario_enhanced.c
# 输出：带类型推断和结构分析

# 3. 完整反编译器（最佳）
nesc complete-decompile mario.nes -o mario_complete.nesl
# 输出：经过完整优化的 NESL 代码
```

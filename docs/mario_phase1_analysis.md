# Super Mario Bros - Phase 1: 深度分析

## 目标

理解 Super Mario Bros 的完整架构，为生成高质量代码做准备

## 分析结果

### ROM 信息

- **大小**: 40KB (40960 bytes)
- **PRG-ROM**: 32KB (2 banks × 16KB)
- **CHR-ROM**: 8KB
- **Mapper**: 0 (NROM)
- **函数数**: 310
- **变量数**: 184
- **代码行数**: 6270

### 内存映射分析

#### Zero Page ($00-$FF) - 184 个变量

**系统变量 ($00-$0F):**
```
$00-$01: ptr0 (16-bit pointer)
$02: ptr1
$06-$07: ptr2 (16-bit pointer)
```

**玩家数据 ($10-$3F):**
```
$1A: 玩家状态标志
$1B-$1F: 玩家相关
```

**敌人/对象数据 ($20-$4F):**
```
$20-$4F: 30 个对象槽位
每个对象可能有多个字节
```

**游戏状态 ($50-$7F):**
```
$57: 重要标志
$58-$6E: 游戏状态变量
```

### 关键函数识别

#### 中断处理

1. **reset() - $8000**
   - 游戏初始化
   - 设置硬件
   - 进入主菜单

2. **nmi() - $8082**
   - VBlank 中断（每帧调用）
   - 主游戏循环
   - 调用多个子系统

3. **irq() - $8040**
   - IRQ 中断（未使用）

#### 核心系统函数

通过调用关系分析，识别关键系统：

1. **主循环系统**
   - nmi() 调用多个子系统

2. **输入处理**
   - 读取手柄输入

3. **物理引擎**
   - 重力
   - 速度
   - 碰撞

4. **对象管理**
   - 敌人
   - 道具
   - 弹跳块

5. **渲染系统**
   - 精灵更新
   - 背景滚动

### 代码模式分析

#### 模式 1: 循环

**汇编模式:**
```asm
LDX #$10
loop:
  ; code
  DEX
  BNE loop
```

**出现次数**: ~50 次
**用途**: 对象遍历、初始化

#### 模式 2: 条件跳转

**汇编模式:**
```asm
CMP #value
BCC skip
  ; code
skip:
```

**出现次数**: ~200 次
**用途**: 状态检查、边界判断

#### 模式 3: 间接跳转表

**汇编模式:**
```asm
ASL A
TAX
LDA table,X
STA ptr
LDA table+1,X
STA ptr+1
JMP (ptr)
```

**出现次数**: ~10 次
**用途**: 状态机、敌人 AI

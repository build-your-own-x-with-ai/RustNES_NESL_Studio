# Super Mario Bros 反编译代码说明

## ⚠️ 关于黑屏

如果你编译并运行 `super_mario_bros.nesl`，会看到**黑屏**。这是**正常的**！

### 为什么黑屏？

反编译的代码**只包含程序逻辑**（PRG ROM），不包含：
- ❌ 图形数据（CHR ROM - 精灵和背景图块）
- ❌ 音乐数据
- ❌ 关卡数据

### 这个反编译代码有什么用？

虽然不能直接运行游戏，但这个代码非常有价值：

#### ✅ 学习游戏逻辑
```nesl
// 可以看到游戏如何工作
fn nmi() {
    if (!zero_flag) {
        sub_90CC();
        t0 = 0xA5;
        sub_8220();
        sub_8E19();
    }
}
```

#### ✅ 理解 NES 架构
- 如何使用零页变量
- 如何处理中断（NMI）
- 如何调用子函数

#### ✅ 作为移植参考
- 将游戏逻辑移植到其他平台
- 理解碰撞检测算法
- 学习物理引擎实现

#### ✅ 编译器技术研究
- 看到真实的反编译输出
- 研究优化效果
- 学习数据流分析

### 完整的 Mario 需要什么？

要运行完整的 Mario，需要：

1. **程序逻辑**（PRG ROM）✅ - 我们有了
2. **图形数据**（CHR ROM）❌ - 需要从原版 ROM 提取
3. **关卡数据** ❌ - 需要手工重建
4. **音乐** ❌ - 需要手工重建

### 如何查看完整的 Mario？

使用原版 ROM：

```bash
# 使用 NES 模拟器运行原版
open "roms/Super Mario Bros (W) [!].nes"
```

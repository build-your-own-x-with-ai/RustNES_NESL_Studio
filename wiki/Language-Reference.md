# 语言参考

基于 `specs/001-nesl-compiler` 与 `specs/002-language-extensions` 的语言契约。

## 词法

- 注释：`// 行注释`、`/* 块注释 */`
- 整数：`123`、`0xFF`、`0b1010`（可含 `_`）；字符 `'A'`（u8）；布尔 `true`=1、`false`=0
- 字符串：`"HELLO"`，支持 `\n \\ \" \0 \xNN`，只能用于常量数组初始化和 `print`
- 标识符：`[A-Za-z_][A-Za-z0-9_]*`

## 顶层声明

```nesl
const SPEED = 2;                       // 编译期整数常量（可用常量表达式）
const PAL: [u8] = [0x0F, 0x30, ...];   // ROM 只读字节数组
const MSG: [u8] = "GAME OVER";         // 字符串常量数组
var x: u8 = 120;                       // 全局变量，初值必须是常量表达式，默认 0
var score: u16;
var buf: [u8; 16];                     // 全局 RAM 数组（清零）
tile 1 = [                             // 8×8 图块：. 或 0 = 透明，1/2/3 = 调色板颜色
  "..3333..", ".3....3.", /* …共 8 行… */
];
map LEVEL = ["####", "#..#"];          // 地图
metasprite HERO = [(0,0,1), (8,0,2)];  // 元精灵
music THEME = "T150 O4 L8 C E G >C";   // 音乐（MML）
sound LASER = (pulse, 0x30, 4, 10);    // 自定义音效
fn add(a: u8, b: u8) -> u8 { return a + b; }
fn main() { ... }                      // 必需，程序入口
```

## 类型

- `u8`（0-255）、`i8`（-128..=127）、`u16`（0-65535），算术回绕。比较结果是 `u8` 的 0/1。
- 字面量 ≤ 255 视为 `u8`，否则 `u16`。二元运算中只要一侧是 `u16`，结果为 `u16`（u8 零扩展）。
- 运算宽度 = max(操作数类型, 目标类型)：`var w: u16 = s + s`（`s: u8 = 250`）结果是 500，不是 244。
- 常量表达式按精确整数计算后再检查能否放进目标类型（负数按补码回绕，`-1` → 255）。
- `u8 → u16` 隐式；`u16 → u8` 必须写 `expr as u8`（取低字节）。
- `i8 as u16` 是**符号扩展**：`-2` → `0xFFFE`。`i8 >> 1` 是算术右移。
- 条件中任何非 0 值都为真。
- `i8` 与非常量 `u8`/`u16` 比较需要显式 `as`；`i8` 的 `* / %` 只支持 2 的幂常量。

## 语句

```nesl
let v: u8 = expr;   let w = expr;      // 局部变量（类型可省略，按表达式推断）
v = e;  v += e;  -= *= /= %= &= |= ^= <<= >>=
arr[i] = e;   arr[i] += e;
if c { } else if c { } else { }
while c { }
loop { }
for i in a..b { }                      // i: u8，不含 b，a/b 只求值一次
break;  continue;  return;  return e;
f(x, y);                               // 表达式语句
```

## 运算符优先级（高 → 低，与 Rust 相同）

| 级别 | 运算符 |
|---|---|
| 后缀 | `f(..)` `a[i]` |
| 一元 | `-` `!` `~` |
| 转换 | `as` |
| 乘除 | `*` `/` `%`（u8 走运行时例程；**u16 不支持乘除**，编译错误） |
| 加减 | `+` `-` |
| 移位 | `<<` `>>` |
| 位与 | `&` |
| 异或 | `^` |
| 位或 | `\|` |
| 比较 | `==` `!=` `<` `<=` `>` `>=` |
| 逻辑与 | `&&`（短路） |
| 逻辑或 | `\|\|`（短路） |

## 结构体

```nesl
struct Enemy { x: u8, y: u8, vx: i8, hp: u8, score: u16 }   // 字段 u8/i8/u16，可尾随逗号

var boss: Enemy;
var enemies: [Enemy; 8];     // 结构体数组
boss.hp = 10;
enemies[i].x += enemies[i].vx;
let e: Enemy;                // 局部结构体，执行到此处时清零
```

不支持：嵌套结构体、整体赋值 / 比较、作为函数参数或返回值。

## match

```nesl
match state {
    0 => title(),
    1 | 2 => { play(); }
    3..=9 => score += 1,
    _ => {}
}
```

模式支持常量表达式、`|` 组合、`a..=b` 闭区间、`_`。按顺序匹配第一个命中的分支，
被匹配的表达式只求值一次。分支体可以是块（后面逗号可省），或单条语句加逗号。

## 声明式资源

### tile

```nesl
tile 1 = ["..2222..", ".222222.", "22322322", "22222222",
          "23222232", "22333322", ".222222.", "..2222.."];
tile '#' = ["33333333", "3......3", /* … */];   // 用字符做索引，配合地图使用
```

每个字符是一个像素：`.` 或 `0` 是透明 / 背景色，`1` `2` `3` 取该图块调色板的对应颜色。

### map

```nesl
map LEVEL1 = [
    "################################",
    "#..............................#",
    "################################",
];
```

最多 30 行 × 255 列；每个字符的图块编号 = 它的 ASCII 码，`.` 视为空格，不足补空格。
查询用 `map_tile(LEVEL1, x >> 3, y >> 3)`。

### metasprite

```nesl
metasprite HERO = [(0, 0, 1), (8, 0, 2), (0, 8, 3), (8, 8, 4, 0x40)];  // (dx, dy, tile[, attr])
let next = metasprite(0, x, y, HERO);   // 返回下一个空槽位
```

dx/dy 可为负；移出屏幕边缘的块自动隐藏。

### music（MML）

```nesl
music THEME = "T140 O4 L8 E G >C< G | A4 G4 R2";
music BASS  = ["O2 L4 C G C G", "A E F G"];   // 多个字符串依次连接
```

### sound

```nesl
sound LASER = (pulse, 0x30, 4, 10);        // (通道, 起始周期, 每帧周期变化, 帧数)
sound BOOM  = (noise, 12, 0, 30, 15);      // 第 5 项：最大音量（默认 12）
sound ZAP   = (pulse, 0x80, -6, 8, 10, 3); // 第 6 项：占空比 0-3（默认 2）
```

### palette_zone

```nesl
palette_zone WORLD = [     // 每个字符 = 一个 16×16 区域使用的背景调色板 0-3（`.` = 0）
    "0000000000000000",
    "1111222211112222",
];                          // 最多 15 行，每行最多 ⌈宽度/2⌉ 个字符
```

## MMC3 中断

声明 `fn irq()` 的程序会编译为 **MMC3（32KB PRG）**。

```nesl
fn irq() {
    split_scroll(0);        // 只能在 irq() 里调用，从当前行起改水平卷轴
}

fn main() {
    scanline_irq(24);       // 每帧在第 24 行触发 irq()；0 表示关闭
    ...
}
```

`irq()` 不能被显式调用，也不能调用用户函数。

## 限制

- 不支持递归、指针。
- 不支持嵌套结构体、结构体整体赋值 / 比较 / 传参 / 返回。
- 数组下标是 `u8`，数组长度 ≤ 256。
- `u16` 不支持 `*` `/` `%`。
- 只支持横向卷轴。

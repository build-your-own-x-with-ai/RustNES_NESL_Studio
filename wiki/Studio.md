# NESL Studio 编辑器

浏览器里的一体化环境：左边写代码，右边立刻跑起来。

- **线上版**：<https://build-your-own-x-with-ai.github.io/RustNES_NESL_Studio/>
- **本地版**：`./target/release/nesc serve` → <http://127.0.0.1:8080>

两者界面相同。区别只在于编译器跑在哪：线上是浏览器里的 WebAssembly，本地是 `nesc serve` 进程。

## 界面

```
┌──────────────────────────────────────────────────────────┐
│ NESL Studio  [示例…▾] [▶ 编译并运行] [⬇ 下载 .nes] [声音] │
├───────────────────────────────┬──────────────────────────┤
│                               │                          │
│  代码区（语法高亮 + 行号）      │   jsnes 模拟器画面        │
│                               │                          │
│  ┌ 代码 / 图块 / 地图 / 调色板 ┐│                          │
│  │ 图块编辑器、地图预览        ││                          │
│  └───────────────────────────┘│                          │
├───────────────────────────────┴──────────────────────────┤
│ 问题 / 汇编清单                                            │
└──────────────────────────────────────────────────────────┘
```

## 模拟器操作

**先点一下画面**让它获得焦点，然后：

| 键 | 手柄按键 |
|---|---|
| 方向键 | D-Pad |
| `X` | A |
| `Z` | B |
| `Enter` | Start |
| `Shift` | Select |

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl/⌘ + Enter` | 编译并运行 |

## 代码区

- **语法高亮**：关键字、内建函数、数字、字符串、注释分色。
- **自动补全**：输入时弹出内建函数列表，带参数签名；中文说明在鼠标悬停时显示。
  补全数据直接来自编译器自己的 `DOCS` 表，所以和编译器永远一致。
- **自动检查**：停止输入 0.5 秒后自动做一次 `check`，有错误的行会标出来。
- **错误跳转**：下方「问题」面板列出 `行:列 说明`，点一下跳到对应位置。

## 可视化编辑（左侧标签页）

| 标签 | 能做什么 | 改动写到哪 |
|---|---|---|
| 图块 | 点格子画 8×8 像素 | 写回源码里对应的 `tile` 数组 |
| 地图 | 画地图格子、预览编译出来的 CHR | 写回 `map` 数组 |
| 调色板 | 从 NES 64 色里选颜色 | 写回 `load_palette` 的参数 |

所有编辑都是**只重写被编辑的那一段声明**，其余代码、注释、排版保持原样，并且可撤销。
地图预览会在后台编译一次（不运行）来取真实 CHR 图形，所以你看到的就是 ROM 里会有的图。

## 其他

- **示例下拉**：内置 8 个示例，选一个就载入源码并自动编译运行。
- **下载 .nes**：编译成功后按钮可用，导出 ROM 用真实模拟器或烧录卡运行。
- **代码自动保存**：源码存在浏览器 `localStorage` 里，刷新不会丢。

## 线上版是怎么工作的

页面是纯静态的，编译器是 WebAssembly：

```
浏览器 → index.html（编辑器 + jsnes 模拟器）
       → pkg/nesc_wasm_bg.wasm（NESL 编译器）
```

`index.html` 会优先用 wasm；找不到 `pkg/` 时（比如你用 `nesc serve` 打开）自动回落到
本地的 `/api/compile` 等接口。两条路径返回的 JSON 完全一致。
构建方式见 [架构](Architecture#浏览器与-github-pages)。
